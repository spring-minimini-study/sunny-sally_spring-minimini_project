## 사진첩 정리 프로젝트

### 1. 프로젝트 개요
당일 촬영한 사진을 하루에 한 번 불러온 후 비슷한 사진들을 묶어서,  
사용자가 스와이프 방식으로 빠르게 정리할 수 있도록 돕는 사진 정리 어플리케이션이다.

###### 핵심 아이디어:
- 전체 사진첩이 아니라 당일 촬영 사진만 정리 대상으로 삼는다.
- 비슷한 사진을 자동으로 묶어 사용자의 판단 부담을 줄인다.
- 체크박스 방식이 아니라 스와이프 중심 UI로 빠르게 정리할 수 있게 한다.
- 즉시 삭제하지 않고 삭제 후보함을 두어 실수 삭제를 방지한다.

### 3. 주요 기능

#### 1) 사진 불러오기
- 안드로이드 사진첩 접근 권한 요청
- 당일 촬영 사진만 조회
- 촬영 시각, 위치, 사진 식별자 등 메타데이터 수집
- 썸네일 생성 및 표시

#### 2) 비슷한 사진 그룹화
- 촬영 시간 기준으로 가까운 사진 묶기
- 위치 정보가 비슷한 사진 묶기
- 이미지 유사도 기반으로 비슷한 사진 묶기
- 각 그룹에서 대표 사진 1장 선정

#### 3) 사용자 정리 UI
- 그룹 단위로 사진 제시
- 대표 사진 중심 카드 UI 제공
- 스와이프 방식으로 keep / delete / skip 처리
- 그룹 내 사진 비교 보기 지원

#### 4) 삭제 후보 관리
- 즉시 삭제하지 않고 삭제 후보함에 먼저 저장
- 사용자가 최종 확인 후 삭제 진행
- 복원 기능 제공

#### 5) 정리 기록 관리
- 오늘 몇 장 정리했는지 기록
- 몇 개 그룹을 검토했는지 기록
- 삭제 후보 수 및 정리 완료 여부 저장

---

### 4. 핵심 동작 흐름

1. 사용자가 앱을 설치하고 사진 권한을 허용한다.
2. 앱이 하루에 한 번 오늘 촬영한 사진을 불러온다.
3. 사진의 시간, 위치, 유사도를 기준으로 비슷한 사진 그룹을 만든다.
4. 각 그룹에서 대표 사진을 선정한다.
5. 사용자는 그룹을 하나씩 확인하며 스와이프로 정리한다.
6. 삭제 대상은 바로 삭제하지 않고 삭제 후보함에 넣는다.
7. 사용자가 최종 확인 후 삭제를 진행한다.
8. 정리 결과와 기록은 서버에 저장된다.

### 5. 프로젝트 구조 정리

#### Flutter 역할
Flutter는 사용자와 직접 맞닿는 기능을 담당한다.

- 사진첩 권한 요청
- 당일 사진 조회
- 썸네일 표시
- 그룹 리뷰 화면 구성
- 스와이프 UI 구현
- 삭제 후보 목록 표시
- 서버와 API 통신

#### Spring Boot 역할
Spring Boot는 사용자 정보와 정리 이력, 그룹 결과 등을 관리한다.

- 사용자 계정 관리
- 디바이스 등록
- 사진 메타데이터 저장
- 정리 작업(Cleanup Job) 관리
- 비슷한 사진 그룹 정보 저장
- 사용자 액션 기록
- 정리 기록 및 통계 조회 API 제공
