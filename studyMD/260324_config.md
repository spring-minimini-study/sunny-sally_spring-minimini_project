# Git Config 범위 정리

Git 설정은 적용 범위에 따라 `--local`, `--global`, `--system`으로 나뉜다.  
같은 옵션이라도 어디에 저장하느냐에 따라 영향을 받는 범위가 달라진다.

## 1. 한눈에 비교

| 옵션 | 적용 범위 | 저장 위치 | 주로 사용하는 경우 |
| :--- | :--- | :--- | :--- |
| `--local` | 현재 저장소만 | 해당 프로젝트의 `.git/config` | 프로젝트별로 다른 설정이 필요할 때 |
| `--global` | 현재 사용자 전체 | 사용자 홈의 `.gitconfig` | 내 PC에서 기본 이름, 이메일을 설정할 때 |
| `--system` | 컴퓨터 전체 | Git 설치 경로의 시스템 설정 파일 | 모든 사용자에게 공통 설정을 적용할 때 |

## 2. 옵션별 정리

### `git config --local`

- 현재 Git 저장소에만 적용된다.
- 다른 프로젝트에는 영향을 주지 않는다.
- 프로젝트마다 다른 사용자 이름이나 이메일을 써야 할 때 유용하다.

예시:

```bash
git config --local user.name "sally"
git config --local user.email "sally@example.com"
```

### `git config --global`

- 현재 로그인한 사용자 계정 전체에 적용된다.
- 가장 자주 사용하는 설정 범위다.
- 새 프로젝트를 만들더라도 기본 설정으로 자동 적용된다.

예시:

```bash
git config --global user.name "sally"
git config --global user.email "sally@example.com"
```

### `git config --system`

- 해당 컴퓨터의 모든 사용자에게 적용된다.
- 관리자 권한이 필요한 경우가 많다.
- 개인 PC보다는 공용 환경이나 회사 PC에서 사용할 가능성이 높다.

예시:

```bash
git config --system core.editor "vim"
```

## 3. 우선순위

Git 설정은 보통 아래 순서로 우선 적용된다.

`local > global > system`

즉, 같은 항목이 여러 곳에 설정되어 있다면 `--local` 값이 가장 먼저 적용된다.

## 4. 간단한 예시

상황:
내 컴퓨터 전체에서는 이름을 `sally`로 사용하고,  
특정 프로젝트에서만 다른 이메일을 사용하고 싶다고 가정하자.

```bash
git config --global user.name "sally"
git config --global user.email "sally@gmail.com"
git config --local user.email "team-project@example.com"
```

결과:

- 이름은 `global` 설정을 사용한다.
- 이메일은 `local` 설정이 더 우선이므로 해당 프로젝트에서는 `team-project@example.com`이 적용된다.

## 5. 실제 실행 결과 해석

아래는 `git config --list --show-origin`처럼 설정 위치까지 함께 확인했을 때 볼 수 있는 예시다.

```text
file:C:/Program Files/Git/etc/gitconfig diff.astextplain.textconv=astextplain
# diff 비교 시 일부 파일을 텍스트로 변환해서 비교하도록 하는 설정

file:C:/Program Files/Git/etc/gitconfig filter.lfs.clean=git-lfs clean -- %f
# Git LFS 사용 시 커밋 전에 대용량 파일을 LFS 포인터로 변환

file:C:/Program Files/Git/etc/gitconfig filter.lfs.smudge=git-lfs smudge -- %f
# checkout 또는 pull 시 LFS 포인터를 실제 파일로 복원

file:C:/Program Files/Git/etc/gitconfig filter.lfs.process=git-lfs filter-process
# Git LFS 필터를 내부 프로세스로 처리

file:C:/Program Files/Git/etc/gitconfig filter.lfs.required=true
# 이 저장소에서 LFS가 필요하면 반드시 정상 동작해야 함

file:C:/Program Files/Git/etc/gitconfig http.sslbackend=openssl
# HTTPS 통신 시 SSL 처리를 OpenSSL로 수행

file:C:/Program Files/Git/etc/gitconfig http.sslcainfo=C:/Program Files/Git/mingw64/etc/ssl/certs/ca-bundle.crt
# HTTPS 인증서 검증에 사용할 CA 인증서 경로

file:C:/Program Files/Git/etc/gitconfig core.autocrlf=true
# 줄바꿈 자동 변환: checkout 시 CRLF, commit 시 LF

file:C:/Program Files/Git/etc/gitconfig core.fscache=true
# 파일 시스템 캐시를 사용해 Git 성능을 높임

file:C:/Program Files/Git/etc/gitconfig core.symlinks=false
# 심볼릭 링크를 실제 symlink로 처리하지 않음

file:C:/Program Files/Git/etc/gitconfig pull.rebase=false
# git pull 시 rebase가 아니라 merge 방식 사용

file:C:/Program Files/Git/etc/gitconfig credential.helper=manager
# Git 자격 증명을 Credential Manager로 관리

file:C:/Program Files/Git/etc/gitconfig credential.https://dev.azure.com.usehttppath=true
# Azure DevOps 인증 시 URL 경로까지 포함해서 자격 증명을 구분

file:C:/Program Files/Git/etc/gitconfig init.defaultbranch=master
# git init 시 기본 브랜치 이름을 master로 생성

file:C:/Users/sally/.gitconfig  user.name=김경민
# 전역 커밋 작성자 이름

file:C:/Users/sally/.gitconfig  user.email=sally0264@naver.com
# 전역 커밋 작성자 이메일

file:C:/Users/sally/.gitconfig  filter.lfs.clean=git-lfs clean -- %f
# 사용자 전역 LFS clean 설정

file:C:/Users/sally/.gitconfig  filter.lfs.smudge=git-lfs smudge -- %f
# 사용자 전역 LFS smudge 설정

file:C:/Users/sally/.gitconfig  filter.lfs.process=git-lfs filter-process
# 사용자 전역 LFS process 설정

file:C:/Users/sally/.gitconfig  filter.lfs.required=true
# 사용자 전역 LFS 필수 설정

file:C:/Users/sally/.gitconfig  core.autocrlf=input
# 줄바꿈 자동 변환: commit 시에만 LF로 변환
# system의 core.autocrlf=true보다 이 값이 우선 적용됨

file:C:/Users/sally/.gitconfig  credential.https://lab.ssafy.com.provider=generic
# lab.ssafy.com 인증 시 generic provider 사용

file:.git/config        core.repositoryformatversion=0
# 현재 저장소의 Git 내부 포맷 버전

file:.git/config        core.filemode=false
# 파일 권한(mode) 변경을 추적하지 않음

file:.git/config        core.bare=false
# 작업 디렉터리가 있는 일반 저장소임

file:.git/config        core.logallrefupdates=true
# 브랜치와 HEAD 변경 이력을 reflog에 기록

file:.git/config        core.symlinks=false
# 이 저장소에서는 심볼릭 링크를 사용하지 않음

file:.git/config        core.ignorecase=true
# 파일명 대소문자 차이를 무시하는 파일 시스템으로 처리

file:.git/config        remote.origin.url=https://lab.ssafy.com/sally0264/homework.git
# origin 원격 저장소 주소

file:.git/config        remote.origin.fetch=+refs/heads/*:refs/remotes/origin/*
# 원격 브랜치를 가져올 때 로컬의 origin/* 추적 브랜치로 저장

file:.git/config        branch.master.remote=origin
# master 브랜치가 추적하는 원격 저장소는 origin

file:.git/config        branch.master.merge=refs/heads/master
# 로컬 master가 원격 master 브랜치와 연결됨

file:.git/config        user.name=sally
# 이 저장소에서만 사용할 로컬 커밋 작성자 이름
# global의 김경민보다 이 값이 우선 적용됨

file:.git/config        user.email=sally0264@naver.com
# 이 저장소에서만 사용할 로컬 커밋 작성자 이메일
```

## 6. 핵심 요약

- 개인 기본 설정은 보통 `--global`로 한다.
- 특정 프로젝트에서만 다르게 설정하고 싶다면 `--local`을 사용한다.
- 여러 곳에 같은 항목이 있으면 `local > global > system` 순서로 적용된다.
