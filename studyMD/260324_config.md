# Git config 범위 정리

Git 설정은 적용 범위에 따라 `--local`, `--global`, `--system`으로 나뉜다.

## 1. 한눈에 비교

| 옵션 | 적용 범위 | 저장 위치 | 주로 쓰는 경우 |
| :--- | :--- | :--- | :--- |
| `--local` | 현재 저장소만 | 해당 프로젝트의 `.git/config` | 프로젝트별로 다른 설정이 필요할 때 |
| `--global` | 현재 사용자 전체 | 사용자 홈의 `.gitconfig` | 내 PC에서 기본으로 쓸 이름, 이메일 설정 |
| `--system` | 컴퓨터 전체 사용자 | Git 설치 경로의 시스템 설정 파일 | 모든 사용자에게 공통 설정 적용 |

## 2. 차이 정리

### `git config --local`

* 현재 Git 저장소에만 적용
* 다른 프로젝트에는 영향 없음
* 프로젝트마다 다른 사용자 이름이나 이메일을 써야 할 때 유용

예시:

```bash
git config --local user.name "sally"
git config --local user.email "sally@example.com"
```

### `git config --global`

* 현재 로그인한 사용자 계정 전체에 적용
* 보통 가장 자주 사용
* 새 프로젝트를 만들어도 기본 설정으로 적용됨

예시:

```bash
git config --global user.name "sally"
git config --global user.email "sally@example.com"
```

### `git config --system`

* 해당 컴퓨터의 모든 사용자에게 적용
* 보통 관리자 권한이 필요할 수 있음
* 개인 PC에서는 자주 쓰지 않고, 공용 환경이나 회사 PC에서 쓸 수 있음

예시:

```bash
git config --system core.editor "vim"
```

## 3. 우선순위

Git은 보통 아래 순서로 우선 적용된다.

`local > global > system`

즉:
같은 설정이 여러 곳에 있으면 `--local` 값이 가장 우선이다.


## 4. 간단한 예시

상황:
내 컴퓨터 전체 이름은 `sally`로 쓰고,
특정 프로젝트에서만 다른 이메일을 쓰고 싶을 때

```bash
git config --global user.name "sally"
git config --global user.email "sally@gmail.com"
git config --local user.email "team-project@example.com"
```

결과:

* 이름은 global 설정 사용
* 이메일은 local 설정이 더 우선이라 해당 프로젝트에서는 local 값 사용
