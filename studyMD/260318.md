2. TestController.java
역할

서버가 정상적으로 실행되는지 확인하기 위한 테스트용 컨트롤러

/test 요청이 들어오면 간단한 문자열을 반환함

코드에서 사용한 어노테이션
@RestController

이 클래스가 HTTP 요청을 처리하는 컨트롤러라는 뜻

반환값을 뷰가 아니라 응답 데이터로 바로 내려줌

@GetMapping("/test")

GET 요청 /test를 이 메서드와 연결

브라우저에서 /test로 들어오면 해당 메서드 실행

정리

이 파일은 스프링 서버가 잘 뜨는지 확인하는 가장 기본적인 테스트용 파일이다.

3. UserController.java
역할

사용자 관련 요청을 처리하는 컨트롤러

클라이언트가 보낸 요청을 받아 서비스 계층에 전달하고 결과를 응답함

담당 기능

사용자 조회

사용자 생성

코드에서 사용한 어노테이션
@RestController

사용자 관련 API 요청을 처리하는 컨트롤러임을 표시

@GetMapping("/users/{id}")

GET 요청 /users/{id}를 처리

사용자 1명 조회에 사용

@PathVariable("id")

URL 경로의 {id} 값을 메서드 파라미터로 받아옴

예: /users/1 → id = 1

@PostMapping("/users")

POST 요청 /users를 처리

사용자 생성에 사용

@RequestBody

요청 본문(JSON)을 자바 객체로 변환해서 받음

예: { "name": "jisu" } → UserCreateRequest

정리

이 파일은 사용자 관련 API의 입구 역할을 한다.

7. User.java
역할

사용자 데이터를 DB 테이블과 연결하는 엔티티

실제로 데이터베이스에 저장되는 객체

코드에서 사용한 어노테이션
@Entity

이 클래스가 JPA 엔티티라는 뜻

DB 테이블과 매핑되는 대상

@Table(name = "users")

테이블 이름을 users로 지정

기본 이름 user 대신 사용해서 예약어 충돌 방지

@Id

기본키(PK) 필드 지정

각 사용자 데이터를 구분하는 고유값

@GeneratedValue(strategy = GenerationType.IDENTITY)

기본키 값을 DB가 자동 생성하도록 설정

저장 시 id가 자동 증가함

정리

이 파일은 DB의 users 테이블과 연결되는 핵심 데이터 객체이다.

8. UserRepository.java
역할

사용자 데이터를 DB에 저장/조회하는 Repository

JPA를 이용해 CRUD 기능을 제공

코드에서 사용한 어노테이션

직접 선언한 어노테이션은 없음

JpaRepository<User, Long> 상속을 통해 스프링이 자동으로 빈 등록 및 구현 제공

의미

save()

findById()

findAll()

deleteById()

같은 기능을 기본 제공받음

정리

이 파일은 DB에 직접 접근하는 계층이다.
